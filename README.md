# Suivi des actions — Team YHD

Sauvegarde de l'application de suivi des actions de l'équipe.

- `index.html` : l'application complète (un seul fichier). Ouvrez-la dans un navigateur.
- Hors de claude.ai, les données sont enregistrées uniquement dans le navigateur (mode local).
- Pour sauvegarder aussi les actions elles-mêmes : bouton **⬇ Exporter Excel**, puis déposez le fichier `.xlsx` dans le dossier `sauvegardes/` de ce dépôt.
